# 📚 Apollo Attendance System

A web-based **Attendance Management System** developed for **Apollo Institute of Computer Application**. The system is designed to make student attendance management easier, faster, and more organized.

## 🚀 Features

* 🔐 Student & Admin Login
* 📊 Attendance Management
* 📝 Assignment Management
* 👨‍🎓 Student Records
* 📅 Attendance Tracking
* 🗄️ Database Integration
* 📱 Responsive & User-Friendly Interface

## 🛠️ Technologies Used

* **HTML** — Structure
* **CSS** — Styling
* **JavaScript** — Frontend functionality
* **PHP** — Backend development
* **MySQL** — Database management
* **Bootstrap** — Responsive UI
